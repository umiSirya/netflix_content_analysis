# Netflix Exploratory Data Analysis (EDA)

## Project Overview

This project was completed as part of the AnalystLab Africa program. The objective was to clean, analyze, and visualize a Netflix dataset containing over 8,800 titles to uncover trends and patterns in the platform's content library.

## Objectives

* Perform data cleaning and preprocessing
* Handle missing values and inconsistent data formats
* Conduct exploratory data analysis (EDA)
* Create visualizations to identify trends and patterns
* Generate insights from the data

## Dataset

The dataset contains information about Netflix movies and TV shows, including:

* Title
* Type (Movie/TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre Categories

## Data Cleaning

The following cleaning steps were performed:

* Handled missing values using appropriate techniques
* Standardized text formatting
* Converted date fields to datetime format
* Checked for duplicate records
* Prepared data for analysis and visualization

## Key Findings

* Movies significantly outnumber TV shows on Netflix.
* Content additions increased rapidly after 2015, reflecting Netflix's expansion.
* The United States contributes the largest share of content on the platform.
* Drama and International Movies are among the most common genres.
* Most content is rated TV-MA or TV-14.
* The catalog is heavily concentrated in recently added titles.
